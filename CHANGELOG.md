# Changelog

All notable changes to HireLens are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2026-XX-XX

### Added
- JD upload and atomic requirement extraction.
- Resume upload with structured extraction and evidence citations.
- Evidence-backed candidate matching and ranked list.
- Per-requirement breakdown with source quotes.
- Natural-language query across the candidate pool with cited snippets.
- Interview question generation (verify, probe_gap, depth, behavioral).
- Interview notes evaluation with unanswered-area detection.
- ChromaDB-backed retrieval.
- Next.js 14 recruiter UI with Tailwind.
- Docker support and CI workflow.

### Security
- API keys loaded from environment only.
